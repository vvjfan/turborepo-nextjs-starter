# Project Overview

This is a **Turborepo Next.js 16 monorepo starter** with two apps (`web` and
`admin`), shared packages (`auth`, `db`, `trpc`, `ui`, `i18n`, `config`,
`tsconfig`, `lib`), and a curated stack: tRPC v11, Better Auth v1.6+ with
email/password + phone + OAuth (GitHub, Google), Kysely ORM on Neon PostgreSQL
with UUIDv7 primary keys, Tailwind CSS v4 with shadcn/ui Base UI components,
and URL-path-based i18n (en / zh-CN) without i18next. The project uses Biome
for linting/formatting, pnpm workspaces, and Turborepo v2 for orchestration.

## Build & Development Commands

```bash
pnpm install              # Install all dependencies
pnpm dev                  # Start dev servers (web :3000, admin :3001)
pnpm build                # Production build everything
pnpm lint                 # Lint all packages with Biome
pnpm lint:fix             # Fix lint issues
pnpm format               # Format code
pnpm type-check           # Type-check all packages

pnpm db:migrate           # Run custom DB migrations (SQL → Kysely)
pnpm db:codegen           # Generate TypeScript types from DB (kysely-codegen)
pnpm db:seed              # Seed the database
pnpm db:setup             # Full DB setup (migrate → codegen → seed)
pnpm auth:migrate         # Better Auth schema migration
pnpm clean                # Clean all build caches

# Per-package commands
cd apps/web && pnpm dev
cd apps/admin && pnpm dev
cd packages/db && pnpm db:migrate
```

## Code Style & Conventions

- **Linter & Formatter**: Biome v2 (no ESLint or Prettier). Run `pnpm lint` or
  `pnpm format` globally.
- **TypeScript**: Strict mode, `moduleResolution: "bundler"`, ES2022 target.
- **Next.js 16 conventions**: `params` and `searchParams` typed as `Promise<T>`
  with `await`. Use `proxy.ts` (not `middleware.ts`). No `src/` directory.
- **React**: Server Components by default; `"use client"` for interactivity.
- **Mutations**: Prefer Server Actions (`"use server"` in `apps/*/actions/`)
  over tRPC mutations.
- **Auth guard**: Use `unauthorized()` (not `redirect()`) in protected Server
  Components.
- **i18n**: Each app owns `app/[locale]/_dictionaries/index.ts` with dynamic
  `import()`. `packages/i18n` provides only locale constants and routing proxy.
  No i18next.
- **Imports**: Use `@/` path alias for app-local imports.
- **Package naming**: `@repo/<name>` (e.g., `@repo/auth`, `@repo/db`).
- **Commit messages**: Conventional Commits (`feat:`, `fix:`, `refactor:`,
  `chore:`, `docs:`). Subject under 72 chars. No emoji.
- **CSS**: Tailwind v4 with `@import` + `@theme` blocks. OKLCH/HSL CSS
  variables for shadcn compatibility.
- **Max line length**: ~100 chars in source files.

## Architecture

**Layer relationship:** Apps → shared packages (`auth`, `db`, `trpc`, `ui`,
`i18n`, `lib`) → external services (Neon PostgreSQL, Better Auth CLI, OAuth
providers).

**Data flow:**
1. **Request → `proxy.ts`** — detects locale via cookie or Accept-Language.
   Admin `proxy.ts` also checks session and redirects unauthenticated users.
2. **Server Components** — read data via `@repo/db` (Kysely) or
   `auth.api.getSession()`. Protected pages call `unauthorized()` to render
   `unauthorized.tsx`.
3. **Mutations → Server Actions** — `"use server"` functions in
   `apps/*/actions/`. Example: `createPost()` validates session, inserts via
   Kysely, then `revalidatePath()`.
4. **Client reads → tRPC** — `@trpc/react-query` integration. tRPC v11 route:
   `POST /api/trpc`.
5. **Auth API** — Better Auth handles routes at `api/auth/[...all]/route.ts`
   (via `toNextJsHandler`).
6. **Auth forms** — Client Components using `authClient` from
   `@repo/auth/client`.
7. **i18n** — Dynamic `import()` in per-app `_dictionaries/`. `packages/i18n`
   provides only locale constants and routing proxy.

## Agent Guardrails

- YOU MUST NEVER modify `packages/db/src/types.ts` — it is auto-generated by
  `kysely-codegen`. Edit SQL migrations and re-run `pnpm db:codegen`.
- YOU MUST NEVER edit `pnpm-lock.yaml` manually — use `pnpm install` or
  `pnpm add <pkg>`.
- No `src/` directories in apps.
- No i18next or accept-language-parser.
- Do not add `@better-auth/kysely-adapter` — Better Auth accepts a `Pool`
  directly (`generateId: false`).
- Every route segment must have `error.tsx` (client component with `reset`).
  Root must have `global-error.tsx`.
- Every app root must have `not-found.tsx`, `forbidden.tsx`, `unauthorized.tsx`.
- No emoji in code or commit messages unless explicitly requested.

## Plugin Points

- **Better Auth**: Add plugins in `packages/auth/src/server.ts`
- **tRPC**: Add routers in `packages/trpc/src/server/routers/`, merge in `_app.ts`
- **UI**: Add components in `packages/ui/src/components/`, export from `package.json`
- **DB**: Add SQL migrations in `packages/db/src/migrations/` as `NNN_description.sql`
- **i18n**: Add locales to `packages/i18n/src/index.ts` and per-app `_dictionaries/`
